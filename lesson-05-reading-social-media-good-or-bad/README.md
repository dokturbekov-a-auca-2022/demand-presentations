# Lesson 05 — The Feed on Trial

Interactive 26-scene HTML lesson for **Reading + Discussion | Social Media:
Good or Bad?** (Pre-Intermediate 2, ages 13–17).

Open `index.html` in a current browser. Keep the `assets` folder beside it so
the three original illustrations remain available offline.

## Controls

- Arrow keys, Page Up/Page Down, Space, or swipe: change scene
- `M`: case directory
- `N`: teacher notes
- `F`: fullscreen or iPhone display instructions

## Visual direction

The lesson is a kinetic youth-magazine evidence file: risograph ink, halftone
grain, torn-paper sections, loud editorial headlines, case tags, and a vertical
page-wipe transition. It deliberately avoids the guild/museum, radio studio,
and stop-motion film-set identities used in earlier lessons.

## Lesson flow

Students move through a personal check-in, visual evidence reading, vocabulary
and pronunciation, matching and categorization, prediction, a three-part
balanced article, gist and detail comprehension, evidence tagging, sequencing,
vocabulary in context, fact/opinion/inference work, discussion, an information
gap, feed-design problem solving, a timed team verdict, review, homework, and an
exit ticket.

The lesson does not require students to disclose account names, private
messages, or personal screen-time data. Alternative reading-only participation
is built into the homework guidance.

The exact prompts for the three original illustrations are in `ARTWORK.md`.

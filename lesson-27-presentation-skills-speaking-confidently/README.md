# Lesson 27 — Stagecraft Studio

Offline interactive Pre-Intermediate 2 presentation-skills lesson: How to Speak Confidently.

Creative identity: a backstage theatre rehearsal. Students work with cue cards, spotlight arcs, hook choices, signposts, visual design, question handling, rehearsal flips, peer director notes, and a one-minute stage talk.

Controls: arrows, Page Up/Down, Space, swipe, `M` stage map, `N` teacher notes.

27 scenes with teacher notes. Local artwork only; no external runtime dependencies.

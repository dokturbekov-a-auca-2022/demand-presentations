# Audio

Three local WAV files were created for teacher-led listening and comparison tasks using installed Windows text-to-speech voices.

- `assets/audio/opening-contrast.wav` - a weak opening followed by a purposeful opening.
- `assets/audio/pace-and-pause.wav` - a rushed delivery followed by a delivery shaped into idea groups.
- `assets/audio/model-mini-talk.wav` - a complete model talk, `Why school clubs matter`, used for main-idea and structure listening.

Audio is user-initiated, pauses when the teacher changes scenes, and has a visible play/pause state.

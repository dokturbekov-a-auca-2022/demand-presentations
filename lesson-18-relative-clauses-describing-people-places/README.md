# Lesson 18 — The Relative Route

Offline interactive Pre-Intermediate 2 English lesson: Relative Clauses | Describing People & Places.

Creative identity: an illustrated town directory / route board. The deck uses rails, labels, sentence bridges, gallery labels, and route clues instead of the card-grid and field-journal language used by earlier lessons.

Controls: Previous/Next buttons, Arrow keys, Page Up/Down, Space, swipe, `M` for route map, `N` for teacher notes.

27 scenes. Local artwork only; no external runtime dependencies.

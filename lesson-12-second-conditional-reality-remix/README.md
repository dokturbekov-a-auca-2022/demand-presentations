# Lesson 12 - Reality Remix Press

Interactive 26-scene HTML lesson for **Second Conditional | Dreams & Hypothetical Situations**.

Audience: Pre-Intermediate 2, ages 13-17. The deck works offline on desktop and mobile.

Open `index.html` in a current browser. Keep the `assets` folder beside it.

Controls:

- Arrow keys, Page Up/Page Down, Space, or swipe to navigate
- `M` opens the print directory
- `N` opens teacher notes
- `F` toggles fullscreen

The deck includes pronunciation audio, Lina's listening pitch, an advice dialogue, grammar discovery, controlled practice, reading, speaking production, a timer, review and exit reflection.

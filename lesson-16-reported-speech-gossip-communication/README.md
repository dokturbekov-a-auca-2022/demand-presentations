# Lesson 16 — Whisper Lab

Interactive 26-scene grammar lesson for **Reported Speech | Gossip & Communication** (Pre-Intermediate 2, ages 13–17).

Open `index.html` in a current browser. The presentation works offline and offers keyboard/swipe navigation, a scene map (`M`), teacher notes (`N`), clickable vocabulary and grammar reveals, communication sorting, say/tell feedback, a timed fluency sprint, pair relay, role play, review and exit ticket.

**Whisper Lab** uses an original paper-collage message-relay identity—violet, lavender, lemon and teal—to make grammar visible without celebrating rumours. It teaches learners to retell information accurately and check before sharing it.

Original artwork and exact prompts are recorded in `ARTWORK.md`.

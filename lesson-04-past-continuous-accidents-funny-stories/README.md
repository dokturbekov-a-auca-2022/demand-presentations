# Lesson 04 - Oops! In Motion

Interactive 24-scene HTML lesson for **Past Continuous | Accidents & Funny
Stories** (Pre-Intermediate 2, ages 13-17).

Open `index.html` in a current browser. It contains all six illustrations
inside the HTML itself, so the single file can be copied, emailed or opened
offline without an `assets` folder.

## Controls

- Arrow keys, Page Up/Page Down, Space, or swipe: change scene
- `M`: scene menu
- `N`: teacher notes
- `F`: fullscreen or iPhone display instructions

## Visual direction

The lesson is a bright handcrafted stop-motion studio: clay characters,
cut-paper sets, colored masking tape, asymmetric compositions and horizontal
scene transitions. It deliberately avoids the dark clockwork/museum aesthetic
used previously.

## Lesson flow

Students move through visual prediction, action vocabulary, collocations,
grammar discovery, form and timeline meaning, when/while, controlled practice,
spoken correction, a short reading, eyewitness interviews, information gap,
fluency storytelling, production, review, homework and an exit ticket.

All accidents are fictional and harmless. Students may invent details rather
than share personal experiences.

The exact prompts for the six original illustrations are in `ARTWORK.md`.

# Lesson 20 — Then / Now

Offline interactive Pre-Intermediate 2 lesson: Used to / Be Used to | Childhood & Habits.

Creative identity: a tactile time capsule with split-era snapshots, polaroid prompts, a meaning dial, sentence flipbook, habit sorting, and a then-now interview. It intentionally avoids the airport signal-board language of Lesson 19 and earlier route/card systems.

Controls: arrows, Page Up/Down, Space, swipe, `M` time map, `N` teacher notes.

26 scenes with teacher notes. Local artwork only; no external runtime dependencies.

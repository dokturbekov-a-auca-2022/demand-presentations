# Audio

Three local WAV files were created for teacher-led listening activities using installed Windows text-to-speech voices.

- `assets/audio/connector-mix.wav` - seven numbered opinions using reason, contrast, result, example, and addition connectors.
- `assets/audio/agree-disagree-dialogue.wav` - a two-speaker discussion showing partial agreement and polite contrast.
- `assets/audio/model-balanced-opinion.wav` - a complete model opinion about controlled phone use in class.

The presentation also uses short Web Audio tones for user-initiated answer feedback and the topic wheel. No sound plays automatically.

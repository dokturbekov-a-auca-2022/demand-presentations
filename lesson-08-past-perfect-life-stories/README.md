# Lesson 08 — The Memory Metro

Interactive 26-scene HTML grammar lesson for **Past Perfect | Life Stories**
(Pre-Intermediate 2, ages 13–17).

Open `index.html` in a current browser and keep the `assets` folder beside it.
The lesson works offline and has no external runtime dependencies.

## Controls

- Arrow keys, Page Up/Page Down, Space, or swipe: change scene
- `M`: Memory Line map
- `N`: teacher notes
- `F`: fullscreen or iPhone display instructions

## Visual direction

The lesson is a cinematic Memory Metro: midnight-blue tiled stations, amber
platform light, vermilion route markers, ticket-cut cards, a right-side line
control, and architectural ink-and-watercolor artwork. The visual grammar is a
route: the Past Perfect station sits before the later Past Simple station.

This direction deliberately avoids the earlier museum, radio, stop-motion,
risograph, neon-newsroom, and Character Hotel identities.

## Lesson route

Students review personality evidence, infer a biography from objects, learn
life-milestone vocabulary and turning-point collocations, revise irregular past
participles, discover the Past Perfect, compare it with Past Simple, practise
form, signals, pronunciation, sentence building, and error correction. They
then read the fictional life story of transit-map designer Lina Rahman,
reconstruct her route, explain the writer's tense choices, interview six
profiles, and produce an original four-station life story.

Personal disclosure is optional; fictional answers are always accepted.

Exact prompts for the seven original illustrations are in `ARTWORK.md`.

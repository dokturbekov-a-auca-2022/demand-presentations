# Lesson 1 — Postcard Exchange

The missing opening lesson for Pre-Intermediate 2: a 28-scene revision, introductions, and seasonal-update lesson. It revisits present simple, present continuous, past simple, future simple, present perfect, there is/are, comparatives, and first conditional through a postcard-exchange narrative.

Open `index.html` in a current browser. It works offline and includes Arrow-key navigation, swipe navigation, a postcard map, teacher notes, and touch-friendly activities.

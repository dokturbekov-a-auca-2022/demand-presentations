# Lesson 15 — Sound Studio

Interactive 20-scene HTML pronunciation and fluency lesson for **Sound Natural in English** (Pre-Intermediate 2, ages 13–17).

Open `index.html` in a current browser with the `assets` folder beside it. It is fully offline. Use arrow keys/Page Up/Page Down/Space or swipe to navigate; `M` opens the track list, `N` toggles teacher notes, and `F` enters fullscreen.

The lesson teaches word stress, sentence and focus stress, connected speech, weak forms, intonation, shadowing, and a short pair mini-podcast. The “Sound Studio” visual system is distinct from the other course lessons.

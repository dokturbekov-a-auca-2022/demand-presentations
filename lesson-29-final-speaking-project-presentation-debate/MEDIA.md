# Media notes

## Local artwork

The lesson uses the three original editorial screenprint illustrations documented in `ARTWORK.md`. Each image is used once as a major teaching visual.

## Model voice

Scene 12 can read the model pitch with the browser's locally available English system voice through the Web Speech API. A full transcript is always visible, and the teacher can read or split the model between two students if speech synthesis is unavailable. No network audio service is required.

## Interface sound

Short feedback tones are synthesized locally with the Web Audio API. Activities retain complete visual feedback when audio is blocked or unavailable.

# Lesson 29 — Forum Mosaic

Offline interactive Pre-Intermediate 2 final speaking project: Presentation or Debate.

Creative identity: a civic forum and mosaic wall. Students choose a route, narrow a topic, build claims and evidence, prepare a presentation or debate, run peer feedback, and reflect on their final speaking growth.

Controls: arrows, Page Up/Down, Space, swipe, `M` forum map, `N` teacher notes.

27 scenes with teacher notes. Local artwork only; no external runtime dependencies.

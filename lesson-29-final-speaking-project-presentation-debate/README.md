# Lesson 29 — Make Your Case

Interactive offline Pre-Intermediate 2 final speaking project for learners aged 13–17.

## Creative direction

`Make Your Case` turns the lesson into a live youth forum and editorial collage. The visual language combines oversized kinetic headlines, evidence stamps, stage lighting, paper textures, bold colour fields and an assembling feedback mosaic. The presentation and debate routes share one standard—clear claim, useful proof, respectful response and purposeful close—without feeling like a traditional template deck.

## Learning route

- 28 teacher-led scenes with concise facilitation notes.
- Presentation and debate route choice, plus lower-pressure participation alternatives.
- Topic randomizer, claim focus lab, evidence court and live claim builder.
- System-voice model pitch with a complete visible transcript.
- Presentation structure, debate structure, linking language and rebuttal practice.
- Argument repair, visual-aid challenge, Q&A rescue deck and role switchboard.
- A locally saved project canvas, three-pass rehearsal director and configurable live timer.
- Audience listening missions, actionable peer-feedback mosaic and exit ticket.

## Controls

- Arrow keys, Page Up/Page Down or Space
- Swipe left/right when the page is not zoomed or vertically scrolling
- `M` for the project map
- `N` for teacher notes
- Browser pinch-zoom and vertical scrolling remain available on phones

Open `index.html` directly or through the shared course viewer. All required visuals and code are local; no external runtime dependency is used.

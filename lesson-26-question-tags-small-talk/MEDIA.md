# Audio

Three local WAV tracks were generated with installed Windows speech voices.

- `tag-intonation.wav`: two deliveries of the same tag for falling/rising comparison.
- `tag-shadowing.wav`: four paced model sentences for pronunciation practice.
- `studio-small-talk.wav`: a three-part school-radio dialogue with five tags and two follow-up questions.

Every audio rail includes a visible play/pause control. Listening tasks explain what students should notice before playback.

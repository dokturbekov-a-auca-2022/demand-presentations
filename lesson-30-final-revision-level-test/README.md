# Lesson 30 — Constellation Review

An interactive final revision and level-test lesson for the English course. The deck uses a night-sky observatory metaphor: each review skill is a star, test rounds form a constellation, and learners leave with a small next-orbit plan.

## Run

Open `index.html` in a browser. Use the arrow buttons, Arrow keys, PageUp/PageDown, Space, swipe gestures, STAR MAP, and NOTE controls.

## Scenes

28 scenes: title, 27 review/test/reflection scenes, including grammar, vocabulary, reading, listening, speaking, error repair, timed test practice, score mapping, and a final exit ticket.

## Visuals

Three original generated visuals are stored locally in `assets/` and used without external runtime dependencies.

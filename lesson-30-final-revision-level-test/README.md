# Lesson 30 — Language Observatory

An immersive 32-scene final revision and classroom level-test mission for older teens. The lesson turns the full course into a language observatory: learners reconnect the course map, recalibrate grammar and vocabulary systems, transmit meaning through reading/listening/speaking tasks, then navigate a scored 15-question test and save a seven-day next-orbit plan.

## Run

Open `index.html` directly or serve the repository as a static site. Everything required at runtime is local.

Controls:

- Arrow buttons, Arrow keys, Page Up and Page Down
- Horizontal swipe away from interactive controls
- `M` for the observatory map
- `F` for distraction-free focus mode
- Optional interface sound and browser-system voice with transcript fallback

## Learning experience

- 32 scenes across Launch, Reconnect, Recalibrate, Words, Transmit, Navigate and Finish zones
- Tense lenses, conditional gate, passive spotlight, reported-speech relay, verb docking and error scanner
- Vocabulary cluster sorter, collocation magnets and phrasal-verb airlock
- Original reading case file with evidence lens
- Offline listening transmission using the browser's system voice and a visible transcript fallback
- Pronunciation stress lab and configurable one-minute speaking roulette
- Fifteen-question final level test with saved answers, score band and an explicit non-certification note
- LocalStorage confidence scan, results, next-orbit plan and exit commitment
- Portrait, landscape, keyboard, touch, reduced-motion and high-contrast support

## Visual system

Nine original local paper-cut illustrations are used once each. Six were created specifically for this rebuild and extend the original observatory art direction across grammar, vocabulary, reading, listening, speaking and the sunrise finale. See `ARTWORK.md` for the asset record.

# Artwork record

All visuals are original generated assets stored locally for this lesson. The shared visual language is a richly textured handmade paper-cut editorial collage: indigo night sky, cyan glow, antique gold, coral accents, diverse older teens, no readable in-image text and responsive wide framing.

| File | Scene and purpose |
|---|---|
| `assets/observatory.png` | Title: learners enter a glowing language observatory. |
| `assets/constellation.png` | Course constellation: course topics connect into four skill galaxies. |
| `assets/grammar-orrery.png` | Grammar orrery: symbolic worlds make time, aspect and possibility visible. |
| `assets/vocabulary-nebula.png` | Vocabulary nebula: travel, technology, personality, work, health, money, media and hobby clusters. |
| `assets/reading-archive.png` | Reading archive: a main idea connects to details, evidence and inference. |
| `assets/listening-signal.png` | Listening room: sound waves reveal main message, details and a turning point. |
| `assets/speaking-launch.png` | Speaking launch: position, reason, example and follow-up form a stable constellation. |
| `assets/test-kit.png` | Level-test kit: compass, timer, response sheets and star tokens. |
| `assets/sunrise-finale.png` | Finale: the completed language constellation becomes a practical path forward. |

Each image appears once in the runtime deck. CSS `object-fit` and scene-specific overlays preserve composition across desktop, phone portrait and phone landscape layouts.

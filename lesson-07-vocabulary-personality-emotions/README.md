# Lesson 07 — The Character Hotel

Interactive 26-scene HTML vocabulary lesson for **Personality & Emotions**
(Pre-Intermediate 2, ages 13–17).

Open `index.html` in a current browser and keep the `assets` folder beside it.
The lesson works offline and has no external runtime dependencies.

## Controls

- Arrow keys, Page Up/Page Down, Space, or swipe: change scene
- `M`: hotel directory
- `N`: teacher notes
- `F`: fullscreen or iPhone display instructions

## Visual direction

The lesson is a warm contemporary Character Hotel: architectural gouache,
curved boutique interiors, room tags, brass-key shapes, an elevator control
rail, terracotta, peacock teal, butter yellow, lavender, and cream. Slides open
like elevator doors. It deliberately avoids the museum, radio, stop-motion,
risograph, and neon-newsroom identities of previous lessons.

## Lesson route

Students distinguish stable personality patterns from temporary emotional
states, learn sixteen target adjectives, practise pronunciation, behavior
definitions, synonyms/antonyms, facial inference, intensity, situations,
classification, and collocations. They then read a contextual group-project
story, reconstruct emotional changes, complete a dialogue, interview six
profiles, build a balanced team, and create an original character check-in card.

The lesson repeatedly reminds students that one behavior, trait, or emotion is
never the whole person. Personal disclosure is optional.

Exact prompts for the four original illustrations are in `ARTWORK.md`.

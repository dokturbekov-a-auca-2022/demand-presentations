# Lesson 10 — Future Postcards

Interactive 25-scene HTML grammar lesson for **Future Continuous | Travel Plans**
(Pre-Intermediate 2, ages 13–17).

Open index.html in a current browser. Keep the assets folder beside it.
The lesson has no external runtime dependencies and is designed for live,
teacher-led online classes.

## Controls

- Arrow keys, Page Up/Page Down, Space, or swipe: change scene
- M: postcard directory
- N: teacher notes
- F: browser fullscreen

## Visual direction

Future Postcards is a playful travel scrapbook: perforated cards, luggage tags,
passport stamps, airport gates, future windows, paper textures, and a moving
“camera” metaphor. It deliberately avoids the metro, newsroom, hotel, radio,
risograph, and stop-motion identities used by earlier lessons.

## Lesson route

The sequence follows the course structure in topicslist: check-in, visual
warm-up, objectives, travel vocabulary, vocabulary sorting, grammar discovery,
meaning, form, time signals, pronunciation, controlled practice, reading
prediction, reading, comprehension, language noticing, pair speaking,
information gap, picture talk, production, review, homework, and exit ticket.

Students use fictional travel situations whenever they prefer. No real booking,
account, location, or personal travel information is required.

# Lesson 25 — Escape Protocol

Offline interactive Pre-Intermediate 2 problem-solving lesson: Survival Game / Escape Room.

Creative identity: an expedition blueprint. Students assign team roles, classify clues, rank priorities, compare routes, unlock decision dials, negotiate supply cards, and present an evidence-based escape plan.

Controls: arrows, Page Up/Down, Space, swipe, `M` mission map, `N` teacher notes.

27 scenes with teacher notes. Local artwork only; no external runtime dependencies.

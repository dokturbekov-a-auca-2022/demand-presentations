# Lesson 12 — Dream Lab

Interactive 24-scene HTML grammar lesson for **Second Conditional | Dreams & Hypothetical Situations** (Pre-Intermediate 2, ages 13–17).

Open `index.html` in a current browser; keep the `assets` folder beside it. It works offline with no external runtime dependencies.

Controls: Arrow keys, Page Up/Page Down, Space, or swipe to move; `M` opens the Dream Directory; `N` shows the scene’s teacher note; `F` enters fullscreen.

The visual identity is **Dream Lab**: original collage-like imaginary worlds in indigo, coral, lavender, and cream. It is intentionally distinct from the travel-scrapbook identity of Lesson 10.

The lesson route: check-in and picture talk → dream vocabulary → grammar discovery, meaning, form and pronunciation → controlled practice → reading → pair and information-gap speaking → group better-world design → quiz, homework, and exit ticket.

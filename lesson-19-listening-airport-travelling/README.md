# Lesson 19 — Terminal Frequency

Offline interactive Pre-Intermediate 2 listening lesson: Airport & Travelling.

Creative identity: a live airport signal desk. Students move through waveform listening loops, transcript windows, boarding tickets, fact locks, route decisions, information gaps, and a travel-desk role-play. It intentionally does not reuse the previous relative-route rails or card language.

Controls: arrows, Page Up/Down, Space, swipe, `M` flight map, `N` teacher notes.

27 scenes. Local artwork only; no external runtime dependencies.

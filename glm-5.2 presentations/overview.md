# Pre-Intermediate 2 Final Revision Lesson

## What was created
A revised, self-contained HTML presentation designed specifically as a **one-hour Final Revision Lesson** for high-school Pre-Intermediate 2 learners in an online classroom.

It focuses only on:
- Comprehensive grammar review
- Vocabulary review
- Speaking review
- Practice activities
- Final level test
- Course reflection

## Key decisions
- Condensed to **16 activity-rich slides** for a realistic 60-minute lesson.
- Removed the earlier long seasonal lesson sequence and made the deck a focused end-of-course revision and assessment session.
- Added significantly more original visual content: six large inline SVG scenes, animated student figures, a finish-line scene, online-class scene, neighbourhood scene, interview scene, progress staircase and celebration scene.
- Added CSS motion for floating objects, character movement, blinking, pulsing, rotating grammar icons, moving paths, staggered entrances and smooth slide transitions.
- Added more questions and tasks while reducing the number of slides: visual vocabulary recall, grammar dashboard, timeline review, 9 grammar practice prompts, neighbourhood description task, vocabulary quiz, six-question interview, progress postcard, eight-question final test, open speaking assessment and reflection prompts.
- Added an interactive 0–8 teacher score control for the open speaking test.
- Preserved phone responsiveness, keyboard navigation, touch swipe, fullscreen, slide overview, progress bar, hidden teacher notes and reduced-motion accessibility.
- No external dependencies or hotlinked images; the presentation runs offline.

## How to use
Open `final-revision-lesson.html` in a modern browser. Use on-screen arrows, keyboard arrows/space, or swipe on touch devices. Press **N** to show or hide teacher notes. Use the fullscreen and overview buttons in the bottom toolbar.

## Lesson timing
- Warm-up: 5 minutes
- Grammar and vocabulary review: 17 minutes
- Practice and speaking: 15 minutes
- Final level test: 15 minutes
- Course reflection: 5 minutes
- Exit and celebration: 3 minutes

## Validation
The HTML document structure, slide count and embedded JavaScript syntax were checked. The final deck contains 16 slides and all required final-revision sections.

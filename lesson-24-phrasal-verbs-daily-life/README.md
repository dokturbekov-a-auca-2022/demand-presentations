# Lesson 24 — Phrasal Verb House

Offline interactive Pre-Intermediate 2 vocabulary lesson: Phrasal Verbs | Daily Life.

Creative identity: a cutaway house and neighborhood. Students open room missions, follow action paths, repair particle/object order, solve daily problems, mime phrasal verbs, and create a three-frame comic.

Controls: arrows, Page Up/Down, Space, swipe, `M` house map, `N` teacher notes.

27 scenes with teacher notes. Local artwork only; no external runtime dependencies.

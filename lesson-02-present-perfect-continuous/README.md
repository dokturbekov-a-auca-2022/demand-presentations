# Lesson 02 — The Guild of Unfinished Things

Interactive HTML presentation for **Present Perfect Continuous | Work & Daily Responsibilities** (Pre-Intermediate 2, ages 13–17).

## Open

Open `index.html` in Chrome, Edge, Firefox, or Safari. It has no online dependencies.

## Controls

- `←` / `→`, Page Up / Page Down, or swipe: change scene
- `M`: scene menu
- `N`: teacher notes
- `F`: fullscreen
- Space: next scene

## Phones and tablets

- Portrait and landscape layouts are supported.
- Long lesson scenes scroll vertically while the navigation bar stays available.
- Vocabulary cards use a two-column touch grid on phones.
- Tap cards and answer choices; swipe sideways to change scenes.
- On very narrow screens, the numeric slide counter replaces the progress bar so every navigation button remains visible.

### Important: open it through Safari, not Files preview

Opening `index.html` directly from Files, Quick Look, a messenger, or an email preview can display the slides while blocking JavaScript interactions.

On the Windows computer:

1. Double-click `start-phone-server.cmd`.
2. Keep its window open and connect the iPhone to the same Wi-Fi.
3. The window prints an `iPhone: http://...:8080` address.
4. Type that complete address into Safari on the iPhone.

If Windows asks about network access, allow access on private networks only.

### Full screen on iPhone

iPhone Safari does not use the desktop page-fullscreen button for this type of presentation. The presentation’s fullscreen control therefore opens the supported Home Screen instructions:

1. In Safari, tap **Share**.
2. Choose **Add to Home Screen**.
3. Open **Unfinished Things** from the new Home Screen icon.

The included Apple web-app metadata and manifest make that launch use standalone app mode without Safari’s normal browser bars.

## Lesson route

The 25-scene presentation includes check-in, visual warm-up, objectives, vocabulary and pronunciation, vocabulary sorting, guided grammar discovery, form and timeline, controlled practice, a reading sequence, speaking tasks, a timed production task, review game, homework, and a three-question exit ticket.

Section 9 uses a **reading lesson** built around “Alex’s Very Long Week.”

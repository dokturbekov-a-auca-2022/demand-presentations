# Lesson 09 — Signal City

Interactive 26-scene speaking lesson for **Technology & AI** (Pre-Intermediate 2, ages 13–17).

Open `index.html` in a current browser. The deck is designed for classroom facilitation, has keyboard and swipe navigation, scene map, teacher notes, interactive vocabulary work, a teacher-read listening script, timers, a group speaking project, and an exit ticket.

## Lesson route

Check-in and previous-lesson bridge → visual lead-in → objectives → vocabulary discovery/matching/categorising → opinion language → controlled practice → teacher-read listening → pair and group speaking → fluency round → mini-podcast production → peer feedback → review → homework → exit ticket.

## Visual direction

Signal City uses original AI-generated collage artwork: luminous communication waves, idea gardens, and an experimental youth audio studio. Its visual system—electric navy, lime, hot pink, cut-paper shapes, rippling signal bars, asymmetric cards—does not repeat the metaphor or layout of the earlier lessons.

## Controls

- Arrow keys, Page Up/Page Down, Space, or a swipe: change scene
- `M`: open the Signal Map
- `N`: show/hide teacher notes

The three original visual assets were generated with OpenAI’s built-in image generation workflow for this lesson.
